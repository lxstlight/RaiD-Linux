## RaiD Linux @VERSION@ «Fennec»

*Создано пушистиками для пушистиков :3*

Главное в этом выпуске — скорость на слабых компьютерах.

### Быстродействие

- **Сжатие памяти (zram).** На ноутбуке с 4 ГБ можно держать открытым примерно вдвое больше, прежде чем система полезет на диск.
- **earlyoom.** Когда память совсем кончается, закрывается самая прожорливая вкладка браузера, а не зависает весь компьютер.
- **Облегчённый режим рабочего стола:** без анимаций, размытия и заставки при входе, рамки окон рисует быстрая тема Breeze. RaiD Aqua остаётся в стиле Mac. Включается сам на компьютерах с памятью меньше 6 ГБ, двумя потоками процессора или без ускорения графики. Переключается в «Добро пожаловать» → «Оформление» → «Быстродействие».
- **Планировщик BFQ** для жёстких дисков и eMMC: система не тормозит, пока диск занят.
- **RaiD Store открывается за доли секунды:** каталог берётся из готового кэша.
- Индексатор файлов ищет только по именам, выключение не зависает на полторы минуты, Firefox реже пишет на диск.

### Исправления

- RaiD Store: кнопки «Загрузить» и «Открыть» на карточках работают сразу; программа запускается сразу после установки; страница больше не зависает на «Подождите…».
- RaiD Aqua: кнопки окон слева, как на Mac.
- Меню загрузки ждёт 3 секунды вместо 5.

### Как обновить установленную RaiD Linux

1. Скачайте **@UPDATE@.zip** из этого выпуска.
2. В Dolphin щёлкните по архиву правой кнопкой → «Распаковать» → «Распаковать в эту папку».
3. Зайдите в появившуюся папку двойным щелчком, щёлкните правой кнопкой по пустому месту → «Открыть терминал в этой папке».
4. Введите команду и свой пароль:
   ```
   sudo sh install-update.sh
   ```
5. Когда появится «Готово!», перезагрузите компьютер.

Интернет нужен только для скачивания архива: все пакеты уже внутри.

### Установка с нуля

GitHub принимает файлы до 2 ГБ, поэтому образ разрезан на части. Скачайте все файлы **@ISO@.part1**, **.part2**… в одну папку и склейте:

- **Windows** (командная строка в этой папке):
  ```
  copy /b @ISO@.part1+@ISO@.part2 @ISO@
  ```
- **Linux:**
  ```
  cat @ISO@.part* > @ISO@
  ```

Проверка образа: контрольная сумма должна совпасть со строкой `@ISO@` в **SHA256SUMS**. Узнать её можно командой `certutil -hashfile @ISO@ SHA256` в Windows или `sha256sum @ISO@` в Linux. Затем запишите образ на флешку (Rufus в режиме DD, Ventoy или balenaEtcher).
